## Downloading the Dataset

To download the dataset, run the following command from the project's root directory:

```bash
bash get_data.sh
```

This will create a `data/` directory containing two subdirectories:

- `data/train/` — Contains the training images.
- `data/validate/` — Contains the validation and test images.
